# MiniGolf Pygame
A fun and customizable mini golf game built with Pygame, featuring multiple levels, a built-in level editor, and support for custom-made courses.

## Description
A mini golf game built in Python using Pygame for gameplay and rendering, alongside CustomTkinter for the dialog and interface system.
Take aim, control your shot power, and guide the golf ball into the flagged hole while navigating around obstacles, barriers, and tricky
course layouts.

The game features 9 built-in levels. In addition to the main levels, the game includes a fully integrated in-game level editor that
allows players to design and customize their own mini golf courses. Save your creations and play them anytime through the Custom Levels
mode, making it easy to experiment with new ideas and share creative challenges.
